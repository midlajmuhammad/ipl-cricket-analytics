# IPL Cricket Analytics

## Project Overview

This project focuses on analyzing IPL cricket data to identify the key factors that influence match outcomes and provide useful insights for franchise preparation and decision-making.

## Business Question

**What actually decides an IPL match, and what does that mean for how a franchise should prepare?**

## Dataset

The project uses **five tables covering 19 seasons** from the approved project data source.

## Project Structure

* `data/raw/` — Raw project data
* `data/processed/` — Processed data
* `sql/practice/` — SQL practice files
* `notebooks/` — Jupyter notebooks
* `reports/figures/` — Analysis figures and charts
* `dashboard/` — Dashboard files

## Setup

### Create Virtual Environment

```bash
python -m venv .venv
```

### Activate Virtual Environment

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### Install Dependencies

```bash
pip install -r requirements.txt
```
